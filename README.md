# Cultural Heritage Sites of Cavite

An Android mobile application developed to showcase and provide information about cultural and historical heritage sites in Cavite, Philippines.

## About the Project

The Cultural Heritage Sites of Cavite application provides users with an interactive way to explore historical and cultural locations throughout Cavite.
The application displays information about heritage sites and uses the Google Maps API to show the location of each site, helping users locate and explore these places.

##  Features

-  Browse cultural and historical heritage sites in Cavite
-  Google Maps integration for displaying heritage site locations
-  Location-based information for each heritage site
-  Camera integration for capturing photos
-  User registration and login
-  Mobile number-based password functionality
-  Bluetooth connectivity
-  Historical information about each heritage site

## 🛠️ Technologies Used

- Android Studio
- Java
- XML
- Google Maps API
- Android Camera API
- Bluetooth
- Gradle



## 🎯 Project Purpose

The application was developed to provide users with an accessible mobile platform for discovering and learning about the cultural and historical heritage sites of Cavite.
